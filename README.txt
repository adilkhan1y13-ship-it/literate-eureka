# Universal Stylish Nickname Generator

Yeh ek simple mobile-friendly nickname generator hai. Interface poora Hinglish mein hai.

## Files
- `index.html` — website ka structure
- `style.css` — design aur mobile layout
- `script.js` — nickname generation aur copy functions

## Android mobile par chalane ka tareeka
1. ZIP file extract/unzip karo.
2. `index.html`, `style.css`, aur `script.js` ko ek hi folder mein rehne do.
3. `index.html` ko browser ya HTML editor mein open karo.
4. Input box mein apna naam/word likho.
5. Category, symbol style aur quantity chuno.
6. `Nicknames Generate Karo` dabao.
7. `Copy Karo` se apna pasandida naam copy karo.

## Important
- Is project mein koi nickname default input ke roop mein nahi diya gaya. Naam khud likhna hoga.
- Generator browser ke andar styles aur symbols combine karta hai; internet/API key ki zaroorat nahi.
- Har game sabhi Unicode symbols ya fonts ko accept nahi karta. Agar naam reject ho, simpler style try karo.
- Yeh tool real-time global trends ko fetch nahi karta; yeh different decorative styles generate karta hai.
